# DPMS Bilibili 安全工作流实施记录

## 目标

将运维页的 Bilibili 准备度检查从只读状态面板升级为可执行工作流，同时保持真实执行的人工确认和全局门禁。

## 实现内容

- 运维页同步加载探针、任务运行记录和真实执行证据。
- 明确显示当前目标活动、门禁建议的安全步骤和执行状态。
- 支持按门禁顺序提交适配器探针或无副作用 `shadow_run`。
- 探针或 Shadow 处于 `queued` / `running` 时阻止重复提交。
- 安全步骤运行期间每 4 秒自动刷新状态，结束后停止轮询。
- 选择器配置步骤仅载入探针草稿，仍要求人工复核后保存。
- 证据齐备后仅引导管理员复核 Real-run 总开关，不自动开启开关或提交真实任务。

## 安全边界

- `shadow_run` 只读取页面状态、检查选择器并保存截图，不点击关注、点赞、评论或转发。
- `real_run` 继续要求管理员权限、请求确认头、请求体确认、全局开关、熔断器和近期证据全部通过。
- 本次改动不包含验证码绕过、反检测规避或平台风控绕过。

## 验证项

- 前端生产构建。
- 运维页桌面和移动视口检查。
- API 请求与浏览器控制台错误检查。
- 容器健康状态检查。
