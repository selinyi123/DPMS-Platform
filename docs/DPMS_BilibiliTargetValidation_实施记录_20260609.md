# DPMS Bilibili 目标校验实施记录

## 问题

历史门禁测试数据使用 Bilibili 首页 URL。首页包含“关注”“点赞”等普通文本，但没有抽奖所需的评论和转发控件，导致探针产生误导性的 `2/4` 结果。

## 修复

- Bilibili 探针、Shadow-run 和 Real-run 只接受视频、动态或可解析短链接。
- 创建、批量导入和自动发现阶段拒绝首页、测试查询 URL 和其他不可执行页面。
- 真实执行证据增加 `target_valid`、`target_kind`、`target_error`、活动状态和原始 URL。
- 运维向导只选择 `pending` / `claimed` 且目标有效的 Bilibili 活动。
- 准备度新增“有效活动”步骤，旧首页探针不会再显示为选择器候选。
- 没有 Bilibili 选择器草稿时，向导内的运行时保存按钮保持禁用。
- 没有有效活动时，向导明确要求到任务编排录入真实视频或动态链接。
- 阻塞目标的策略评分固定为 `0`，避免无效记录进入高优先级队列。

## 安全结果

无效目标无法进入会打开外部页面的探针、Shadow-run 或 Real-run。现有历史测试记录保留用于审计，但不会再被自动工作流选择。
