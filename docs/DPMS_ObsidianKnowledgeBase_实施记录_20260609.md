# DPMS Obsidian 知识库实施记录

## 背景

DPMS 的实施记录原本分散在仓库 `docs/`、Git 提交历史和 Obsidian 旧 `DPMS` 目录中，缺少统一入口和持续同步机制。

## 实现

- 在当前 Obsidian Vault 中建立独立的 `DPMS-Platform` 项目知识库。
- 保留旧 `DPMS` 目录，不覆盖其中的项目恢复资料。
- 将仓库 README、路线图、全部实施记录、审查清单和附件按主题分类同步。
- 将旧 `DPMS` 目录的三份恢复资料复制到 `01_项目基线/历史恢复资料`。
- 新增项目主页、Git 提交活动时间线和里程碑记录规范。
- 新增 `scripts/sync_obsidian.ps1`，支持重复同步和只读一致性校验。

## 数据原则

- 仓库文件是技术记录的权威源。
- Obsidian 是检索、串联和阅读入口。
- 同步采用复制和哈希校验，不删除 Vault 中的额外个人笔记。
- 旧恢复资料只复制，不移动或改写。

## 验证

- 检查每个源文件在目标分类目录中存在。
- 使用 SHA-256 比较仓库源文件与 Vault 副本。
- 验证项目主页中所有 Wiki 链接均能解析到唯一 Markdown 文件。
- 实际同步并校验 **27 个文件**。
- 实际校验 **32 个 Wiki 链接**，无缺失或歧义。
